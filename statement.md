# Project Statement

## Problem Statement

Students often have difficulty managing multiple study tasks, planning their study time, remembering when to revise topics, and maintaining focused study sessions. A messy study schedule can hamper their academic results.

Study-Planner provides a single application for managing study tasks, creating study plans, scheduling revisions using spaced repetition, and having focused short study session using pomodoro timer.

## Project Scope

The project focuses on providing a simple command-line study management system for students.

The system includes:

- Study task management
- Study plan creation and viewing
- Spaced repetition for revision scheduling
- Revision progress tracking
- Pomodoro study sessions
- Local JSON-based data storage
- Basic input validation and error handling

The project is designed as a local Python application and does not require online database or external web service.

## Target Users

The primary target users are students who want to organize their academic study activities and manage revision schedules.

The application is particularly useful for students who need to:

- Track study topics and tasks
- Plan study sessions
- Remember revision dates
- Maintain focused study sessions

## High-Level Features

### 1. Task Management

Users can add, view, complete, and delete study tasks.

### 2. Study Planning

Users can assign a study date and duration to their study tasks and view their planned sessions.

### 3. Spaced Repetition

Users can add topics for revision, track revision progress, schedule subsequent revisions, and delete revision entries.

### 4. Pomodoro Timer

Users can start a focused study session using a Pomodoro timer with an alarm when the session ends.

### 5. Data Storage

The application stores study tasks, revision information, and session data locally using a JSON file.
